# Part A — Easy Level Questions

## 1. Inner Join

### Requirement
Display Patient Name, Doctor Name, and Appointment Date for completed appointments.

```sql
SELECT
    p.patient_name AS `Patient Name`,
    d.doctor_name AS `Doctor Name`,
    a.appointment_date AS `Appointment Date`
FROM appointments a
INNER JOIN patients p
    ON a.patient_id = p.patient_id
INNER JOIN doctors d
    ON a.doctor_id = d.doctor_id
WHERE a.status = 'Completed';
```

## 3. Join + Window Function — ROW_NUMBER()

### Requirement
Return the most recent appointment for every patient.

```sql
WITH ranked_appointments AS (
    SELECT
        p.patient_name,
        a.appointment_date,
        d.doctor_name,
        ROW_NUMBER() OVER (
            PARTITION BY p.patient_id
            ORDER BY a.appointment_date DESC, a.appointment_id DESC
        ) AS rn
    FROM patients p
    INNER JOIN appointments a
        ON p.patient_id = a.patient_id
    INNER JOIN doctors d
        ON a.doctor_id = d.doctor_id
)
SELECT
    patient_name AS `Patient Name`,
    appointment_date AS `Appointment Date`,
    doctor_name AS `Doctor Name`
FROM ranked_appointments
WHERE rn = 1;
```

### Requirement
Rank doctors according to total billing revenue.

# Quick Revision — Window Functions Used

| Function | Purpose | Used In |
|---|---|---|
| `ROW_NUMBER()` | Gives a unique sequence number | Latest/first records, top records |
| `RANK()` | Gives the same rank to ties and leaves gaps | Revenue/fee rankings |
| `DENSE_RANK()` | Gives the same rank to ties without gaps | Revenue leaderboard |
| `LAG()` | Gets the previous row's value | Previous appointment/bill |
| `LEAD()` | Gets the next row's value | Next appointment |
| `SUM() OVER()` | Calculates a running/window total | Running revenue |
| `PARTITION BY` | Creates independent groups for a window function | Patient/doctor/city analysis |

# Important SQL Patterns

## Pattern 1 — Latest Row Per Group

```sql
ROW_NUMBER() OVER (
    PARTITION BY group_id
    ORDER BY date_column DESC
)
```

Then:

```sql
WHERE rn = 1
```

## Pattern 2 — Top N Per Group

```sql
ROW_NUMBER() OVER (
    PARTITION BY group_column
    ORDER BY measure DESC
)
```

Then:

```sql
WHERE rn <= N
```

## Pattern 3 — Previous Value

```sql
LAG(value_column) OVER (
    PARTITION BY group_column
    ORDER BY date_column
)
```

## Pattern 4 — Next Value

```sql
LEAD(value_column) OVER (
    PARTITION BY group_column
    ORDER BY date_column
)
```

## Pattern 5 — Running Total

```sql
SUM(amount) OVER (
    PARTITION BY group_column
    ORDER BY date_column
    ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
)
```

## Pattern 6 — Rank

```sql
RANK() OVER (
    ORDER BY measure DESC
)
```

## Pattern 7 — Rank Within a Group

```sql
RANK() OVER (
    PARTITION BY group_column
    ORDER BY measure DESC
)
```
